# 08 — References & External AI Resources

## 1. Official Standards & Documentation
- **Pune Municipal Corporation (PMC)**: Citizen grievance guidelines, ward hierarchy, and departmental service charters.
- **National e-Governance Division (NeGD)**: CPGRAMS standards, Open API recommendations for municipal service integration.
- **FastAPI Documentation**: Modern, high-performance web APIs with Python and Pydantic. https://fastapi.tiangolo.com/
- **Google Gemini API**: Structured outputs, multimodal inference, and prompt injection mitigation best practices. https://ai.google.dev/
- **Next.js 15 App Router**: Modern full-stack React framework with server components and streaming. https://nextjs.org/docs
- **Leaflet & OpenStreetMap**: Open-source mobile-friendly interactive maps. https://leafletjs.com/
- **WCAG 2.1 Guidelines**: Web Content Accessibility Guidelines for public civic interfaces. https://www.w3.org/WAI/standards-guidelines/wcag/
